# 高频波形插值验证

[实际XSim摘要](simulation_summary.txt)：新带限插值解析黄金值、signed/背压/复位契约、实际UART、旧计算路径与真实顶层连接检查。
本轮14个行为仿真顶层、140项离线主机测试通过。新系数生成器无第三方依赖，ROM检查及0～600kHz抽样频点复数响应测试通过。

新数值测试独立对照连续正弦与100/300/500kHz复合波，包含每周期恰好10样点的409.6kHz相干采样，避免靠额外相位样点绕过插值问题。
500kHz、10000码峰值案例的最大样值误差约59.6码；240个绘图点对连续波形的Y误差不超过2像素。
不是实板误差或全部输入的精度保证；原时域Vpp/RMS和FFT计算未修改。
