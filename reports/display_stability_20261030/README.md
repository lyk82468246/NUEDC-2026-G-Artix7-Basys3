# 显示稳定性修订：离线验证

[验证摘要](simulation_summary.txt)摘录本轮实际XSim日志的PASS和仿真完成位置。完整临时日志位于test_results对应目录，不纳入版本控制。

覆盖11个仿真顶层：新基波相位/周期估计、真实复合样本逐点插值、实际UART命令与细化时间刻度、4组旧显示协议回归、3种布局计算回归，以及快照/实际顶层接口。
主机原有离线测试116项通过；合并远端AFG1022验收工具后，其新增3项离线测试也单独通过（合计119项）。顶层检查中的DSP IP为黑盒；串口测试不模拟屏幕内部刷新引擎。

本报告不是新实现报告，也不是实屏验收。资源、时序、固件刷新命令支持及物理效果须重新构建并上机确认。
详细算法、参数、测试入口及手动流程见[说明](../../docs/display_stability_20261030.md)。
