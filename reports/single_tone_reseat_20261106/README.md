# BNC/SMA重新连接后单音复测（2026-11-06）

## 结论

用户重新插紧BNC/SMA后，同样四个频点全部恢复为单候选、signal_valid=1。此前失效的100kHz和42kHz均恢复，约189～189.5kHz峰不再进入候选。结合只改变连接、没有改RTL/门限/校准参数的前后对照，本次故障有力指向模拟连接接触问题。不能由候选表断言该频段绝对无噪声，也不能外推全频段全部通过。

## 历史经验与纠正

[2026-10-23 BNC恢复记录](../../docs/bnc_recovery_20261023.md)已记载BNC松动、约5.2us背景（约192kHz）及189kHz候选，插紧后恢复。这次助手在发现189kHz弱峰时漏用了该记录，应该优先提醒检查BNC/SMA，而非先建议改判定逻辑。今后遇到同类固定弱峰，先核对连接、终端及供电，并作相同设置前后复测；不能单凭频率接近断言确定的电路振荡机理。
