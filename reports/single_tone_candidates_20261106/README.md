# 单音散点失效：实板候选谱峰取证（2026-11-06）

## 后续更正

用户重新插紧BNC/SMA后，相同四个单音频点均恢复为单候选有效帧，见[重新连接复测](../single_tone_reseat_20261106/README.md)。10月23日已有同类BNC松动及约189kHz背景记录，助手本轮漏用了历史经验；应先排除接触问题，暂不以修改RTL或放宽判定作为本次故障处理。下文保留连接修复前的取证事实与当时分析。

## 条件与边界

AFG1022 SN1931131 / V1.2.4；CH1纯正弦、HIGHZ显示负载、200mVpp设定、0V偏置、CW，调制与耦合关闭。沿用现有滤波器→ADC→FPGA接线，A模式连续测量。脚本独占AFG会话，每次采集前后查询配置完全一致；每频点捕获一个新measurement_valid事件，schema3原始候选。测试结束CH1/CH2均确认OFF。没有烧写FPGA、修改校准参数或保存Flash。

HIGHZ设定不是对50Ω负载端实际电压的独立校准。本轮没有读取完整8192点波形或完整频谱；短ILA ADC窗口不用于推断全帧波形质量。

## 判定链解释

100kHz主峰bin200正确，但第二峰bin378（189kHz）导致现有Component_Analyzer谐波一致性失败；42kHz主峰bin84正确，第二峰bin379（189.5kHz）同样失败。主峰未消失，也没有采集超时。

弱峰约0.60%～0.94%，超过当前主峰/256的相对门限与8倍谱背景门限，因此被保留为候选。11kHz的bin22/379以及12kHz的bin24/378被现有随谐波阶次增加的容差接受：分别余数5/18、阶次17/15、容差10/9（后者距下一整倍数6）。它们因此通过；这不证明弱峰是真实输入谐波。

这组证据确认了所测失效帧的直接拒绝机制，并能解释随频点变化的通过/拒绝。约189～189.5kHz弱峰的来源仍未定位，可能属于模拟、采样或数字链路；当前证据不能归因于其中某一级。仅四个频点、每点一帧，不代表完整扫频统计。

## 后续

先用实测候选回放建立回归，审视按模式保留主频/谐波的判定策略，避免一个弱非谐波峰清空全部读数，同时保留杂散告警与真实弱谐波检测能力；不应仅硬编码189kHz陷波或盲目提高全部门限。随后需多帧/幅值变化与完整频谱或原始帧证据区分弱峰来源。本轮仅取证，不修改RTL。
