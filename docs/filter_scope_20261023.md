# 滤波器独立示波测量（2026-10-23）

后续修订：用户查出发生器至滤波器BNC松动，插紧后看到干净正弦；恢复整链的结果见[BNC恢复复测](bnc_recovery_20261023.md)。下列读数属于修复前状态，不能继续用来认定滤波器本体故障或要求立即重焊。

## 目的与接线

定位含滤波器时 FPGA 额外谱峰的来源，不修改 RTL、门限或已烧写固件。
用户临时改接：HDS OUT → 滤波器 → HDS CH1，ADC 模拟输入断开。
CH1 是 BNC/SMA 同轴直连，不是 10× 探头，因此软件倍率改为 1×。
发生器限幅 100mVpp、HIGHZ、零偏置；测试结束已回读确认 OUT OFF，并关闭服务。

用户补充：运放 SGM8302；±5V 来自现成电源模块；输入约 50/51Ω 并联对地，输出约 50/51Ω 串联。尚缺原理图、滤波器设计增益、电源模块型号、ADC 模块实际输入阻抗。

## 仪器设置与数据质量

原 CH1 为 10×、AC、1ms/div，不用于电压定量结论。
修正为 1×、DC、采样模式、8K 深度；2µs/div 时回读 250MSa/s，20µs/div 时为 25MSa/s。
OFF 测量使用 100mV/div，ON 使用 500mV/div。
第一次配置后的屏幕波形返回全零，舍弃该波形；等待后重复采集才获得非零数据。
SCPI 返回的 600 字节是屏幕波形，不应当作 8K 原始 ADC 记录，不能直接套采样率做 FFT。
配置及测量是顺序查询，并非原子同步快照；自动频率和头部频率曾不一致。

## 解释边界

1. ±5V 在 [SGM8302 厂家额定范围](https://www.sg-micro.com/product/SGM8302) 内，但供电纹波、退耦及反馈网络稳定性尚未验证。
2. HIGHZ 是发生器负载标定设置，不代表输出内阻为零。50Ω 输入会参与分压；未实测滤波器输入电压，不能把 1.13V/0.1V 当作电路增益。
3. 输出串联电阻与接收负载分压：近似 `Vload=Vsource*Rload/(Rseries+Rload)`。若接收端为 50Ω，串联 50Ω 约减半；高阻接收近似不减半。这只是条件推导，ADC 端阻抗未确认。
4. OUT OFF 不等于输入接地，OFF/ON 平均值明显变化；目前不能将 OFF 读数当作精密零输入噪声测试。
5. ADC 已断开，负载条件改变。尚未证明实际模拟输出存在 189kHz，也未排除接回 ADC 后的负载/接地效应或高频混叠。禁止据此添加固定频率陷波或调整门限掩盖问题。
