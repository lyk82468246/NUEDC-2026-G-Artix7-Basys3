# 高频波形折线：原因、修订与验证

2026-10-30。本轮修改显示重建，不改变ADC采样率、时域统计、FFT、频率估计或标定系数。

## 原因核对

当前有效显示路径是Display_HMI→Display_Wave_Renderer，直接读取完整8192点时域BRAM副本。
FIR的Decimation_Rate=1。没有“全帧固定抽成240点、再截取1T/3T”的前置降采样。
旧renderer先确定周期窗口，再按像素求分数地址，但只在相邻两个样点之间连直线。

| 单音频率 | 每周期真实ADC点数 | 1T铺满240像素时，每个样点间隔约占像素 |
| --- | --- | --- |
| 10kHz | 409.6 | 0.58 |
| 100kHz | 40.96 | 5.83 |
| 200kHz | 20.48 | 11.67 |
| 500kHz | 8.192 | 29.17 |

因此频率越高，线性插值形成的长直线段越明显。500kHz正弦在峰顶附近的半间隔线性插值偏差可约为
`1−cos(π×500000/4096000)=7.26%`峰值。这是两点插值方法的限制，不能把它归咎于屏幕分辨率，
也不代表满足采样定理的带限信号只能画成八边形。

## 本轮RTL

新增Display_Bandlimited_Interpolator和Display_Interpolation_ROM：

- 16抽头、64个分数相位的Blackman窗sinc核，系数signed Q2.14；每相位DC系数和精确为16384。
- 每个输出点使用16个真实signed BRAM样本，不从FFT三条谱线或基波正弦合成曲线。
- Q12地址四舍五入到最近1/64采样间隔，分数溢出正确进位至下一整数地址。
- 使用一个分时16×16乘法器累加，启用时显式编译掉原线性插值乘法器；设计意图不增加DSP总数。
- 1024×16同步系数ROM，设计意图增加一块RAMB18（0.5 BRAM Tile），不增加整帧/整屏缓冲。

有符号累加后舍入并饱和到16-bit，保留溢出/地址边界诊断。
正常有效频段使用相同基波相位往后移动4个整周期作绘图起点，给16抽头提供前向历史样本；仍显示相同相位的1T/3T。
10～500kHz时所需窗口和两侧抽头均位于8192点帧内。对齐失败时采用保守起点，越界则显式钳位并报告window_clamped。

为避免重建后峰值超过离散样本Amax造成削平，先预计算全部240点，扩大所需纵轴范围，再计算轴标定及真正发送。
坐标仍是对称±轴范围；Vpp、RMS和FFT数值字段继续来自原测量链路。新增预计算不输出串口点，不会重复发送480点。
高频相干采样还可能使原Vpp离散最值漏掉模拟峰顶，此问题与绘图平滑独立，不能用显示修复宣称测量Vpp也被修正。

顶层DISPLAY_WAVE_BANDLIMITED默认1，可设0回到旧两点插值作对照。独立renderer的BANDLIMITED默认0，保持旧数值测试兼容。
显示时间基准、HOLD整帧冻结、刷新协议、文字ref及FFT左右补偿不变。

## 验证

以下为10000码正弦峰值基准的行为仿真，与连续解析波形逐点比较，不是实板结果：

| 案例 | 输出 | 最大样值误差（码） | RMS样值误差（码） |
| --- | --- | --- | --- |
| 10kHz | 1T | 2.15 | 0.81 |
| 100kHz | 3T | 13.01 | 5.00 |
| 200kHz | 1T | 24.14 | 10.05 |
| 409.6kHz，恰好10样点/周期 | 1T | 47.08 | 20.05 |
| 500kHz | 1T | 59.59 | 24.77 |
| 500kHz，改变初相 | 3T | 59.12 | 24.63 |
| 100/300/500kHz复合，分量峰值5000/3000/2000码 | 3T | 22.83 | 7.22 |

500kHz单音最大误差约为峰值0.60%，主要受64相位地址量化影响；测试中240个Y坐标与连续波形目标相差不超过2像素。
这不是全频段/任意组合的绝对电压精度保证。

入口scripts/run_display_bandlimited_sim.ps1包含连续波形黄金值与独立插值器契约两组顶层；
还检查−32768、32767、DC归一化、相位进位、边界、正负饱和、背压和复位。
原UART回归明确禁用新插值保留黄金值，另一个完整HMI集成案例使用新默认路径，验证输出仍为每帧240点及同帧轴/停止位释放。
系数生成器及主机测试验证0～600kHz抽样频点的复数响应和原始谐波保持。

本轮140项离线主机测试通过；显示、插值、相位、UART和真实顶层契约的行为仿真均通过。详见reports/waveform_interpolation_20261030。

## 工程与手动上机

新增两个显示源文件，GUI需要重新登记；不能仅保存旧的内存工程列表：

```tcl
source {C:/Users/Joe/Documents/Verilog/G_FPGA/scripts/setup_display_prepare.tcl}
```

应看到11条REGISTERED，包含Display_Interpolation_ROM、Display_Bandlimited_Interpolator。
用户随后手动综合、实现、检查WNS/hold/资源/DRC、生成bit及匹配LTX并下载；本轮未代为构建或下载。
用户GUI生成的只读Flash VIO IP和ENABLE_FLASH_READONLY_PROBE设置予以保留；本轮不访问Flash或仪器。
当前器件DSP已用满，新的DSP/BRAM映射必须以新报告确认，不能将“替换一个乘法器”的结构意图当作资源签核。

先比较100/200/409.6/500kHz单音的1T与3T，再看带高次谐波的非对称复合波：应更平滑且畸变仍在。
屏幕240×160的整数像素与有限采样带宽仍会限制细节，不以把真实畸变抹成正弦为通过标准。
