## 3. 构建发现与修复

1. XDC 中 Tcl `for` 不受该约束解释器支持，首次尝试已停止；改成显式逐管脚约束，未降低 DRC 严重级别。
2. 数码管 Hz/100 组合除法导致综合估计 WNS=-5.243 ns，停止当轮实现并改为32拍串行除法。全32位输入、边界、重启及LED位映射自检通过；修订后综合估计 WNS=+0.130 ns。此数值不是最终布线 WNS。
3. 发现本轮新增 Python 模型遗漏 CORDIC 输出增加一位小数位的二倍raw增益；修正模型并以真实IP网表确认，FPGA FFT/CORDIC配置与数据通路未因此改变。
4. 完整构建脚本补充保持时序门限（WHS≥0）与 route/bus_skew/check_timing/CDC/methodology 报告。外部ADC约束的物理假设仍须实测复核。
