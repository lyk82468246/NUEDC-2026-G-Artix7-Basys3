## 2. 判决与位宽

```text
频域BRAM → 三轮最大候选（每轮排除已选主瓣±6bin）
          → 第四轮排除全部候选主瓣后累加背景/计数
          → 44拍串行除法求均值 → 候选幅值 > 8×背景均值
          → 压紧候选表 → 按频率排序 → 近似谐波一致性
时域RMS ────────────────────────────────┤
                    谱有效 AND RMS≥64raw → 本帧有效
```

背景求和44位，覆盖最多3991个32位幅值；均值除法不引入宽组合除法器。8倍阈值饱和到32位，不能溢出回小数。原有绝对门限64raw（谱幅单位）和相对最强峰1/256门限保留；它们与时域RMS的64raw不是同一物理量。谐波阶数计数扩展到9位，覆盖调试范围bin10～4000的400阶情况。

RMS门限64raw是该链路的初步可调门限：实测OFF=20、50mVpp/100kHz=313。它不是通用输入电压阈值，不代替全频带/量程/温度测试和mV校准。谱峰/背景均值比也不是经校准的功率SNR dB；可抑制宽带噪声，但低电平相干杂散仍需RMS门限。任意弱基频、缺失基频或落在噪声下的分量不保证识别。
