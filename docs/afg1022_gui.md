# AFG1022 Tkinter 测试台

在工程根目录运行：

```powershell
.\scripts\afg1022_gui.ps1
```

使用现有 `.venv-hds` 的 Python、Tkinter、PyVISA 和系统 VISA，无需额外图形库。底层为已实测的 `afg1022.py`（大端 DAC 上传、全表回读）；窗口打开时不连接设备、不改变正在输出的信号。

## 使用

1. 点“扫描设备”，选择 VISA 资源，再点“查询状态”核对设备序列号和输出。
2. 选择 A/B/C，点“载入该模式示例”，或自行修改参数。
3. 点“预览 / 校验”，查看被测信号的 Upp、RMS、各分量峰值和波形。
4. “上传（保持 OFF）”上传配置后保持两路关闭；“上传并开启”上传并开启选定通道。每次均使用按钮点击时的参数。
5. “关闭两路输出”停止输出。窗口退出会保留输出，需停止时先关闭两路。

## 参数与模式

- 分量频率由基频 kHz × 整数谐波阶数确定。第一行阶次必须为1；选择2或3个分量，幅度为 **峰值 mV**，相位为度。
- A：所有分量10～200 kHz，被测总Upp100～250 mV；B/C：所有分量10～500 kHz，总Upp50～250 mV。超出总Upp范围会标记扩展测试，不会自动缩放。
- C：可设1～10 MHz单频干扰、幅度及相位。标准幅度为 **200 mVpp**；其他幅度标记扩展测试。本工具的频率范围不代表覆盖题目全部 fJ≥1 MHz。
- C的“仅被测信号／仅干扰／混合信号”使用相同满量程和整表频率，便于对照，避免减去干扰后改变被测分量幅度。
- 表长支持256～8192点。程序求共同周期，并自动选择每张表的周期数，要求最高分量每周期至少8点、等效采样率≤125 MSa/s。不能在表长内精确表示的频率组合会报错；不会静默改变频率或制作不连续表。
- 仪器整表频率可能低于被测基频。例如表内16个125 kHz周期对应整表7.8125 kHz。预览显示被测信号一个周期，不包含C干扰。
- 零偏置；两路可选，但上传覆盖共享EMEM并关闭两路。每次开启均重新上传，防止参数编辑后误开旧表。切换模式示例只改界面参数。

HIGHZ与50 Ω选项是源的幅度显示约定，不改变物理50 Ω输出内阻。HIGHZ标称值接实际50 Ω负载后约减半；历史项目校准采用HIGHZ标称约定，改变负载设置须重新核对。所有参考值为理想源设置值，不是端口实测值；满量程Vpp不等于复合波总Vpp。

制表不添加随机噪声。此前的随机噪声测试文件仍保留在tmp；本界面聚焦赛题三个要求。

保存/载入参数使用JSON；导出波形JSON包含归一化samples、config及参考值。用底层命令重放时须明确传入config中的hz、vpp、load，不会自动读取这些字段。

通信在后台线程中执行，窗口不因USB查询阻塞。通信中点关闭输出会请求在当前传输完成后关闭，须等实际状态回读；通信故障会尝试发送OFF，但无法保证硬件接收，日志提示未确认时应核对面板。窗口不提供FPGA控制；单次测量须在板上切换相应模式并按BtnD。

## 已知测试点

当前弱基波案例为125/375/500 kHz，峰值5/25/20 mV，第三谐波相位90°；无干扰理论Upp87.7546 mV、RMS22.9129 mV。用户反馈1/2/3 MHz、200 mVpp干扰时正常；3.5 MHz测得Upp136.5 mV、RMS30.1 mV，时域超限；4 MHz判定无效。这些是本次接线与校准状态下的反馈，不是所有信号组合验收通过。
