按[现场操作手册](../contest_acceptance_runbook.md)先离线生成新文件并dry-run，再由操作者核对幅值、负载、用户槽后上传。A向量的幅值条件超出此前100 mVpp试验包络，须先检查模块余量；文件存在不代表已经获实板验证。C干扰不在这些文件中，现有multitone入口拒绝超过500 kHz的分量，不能拿A/B向量冒充C已测。
