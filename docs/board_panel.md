# 板载操作面板与阶段验证

日期：2026-10-23。本文描述新增 P2 RTL，不表示旧 bit 已升级或实板验证通过。原有测量数据仍为 raw，尚未标定成 mV。

## 1. 架构与事务边界

```text
SW15, SW3:0 → 双触发同步/20ms稳定滤波 → Run_Controller
BtnU/D/L/R → 各自同步消抖 ────────────────┤
                                        ├→ 帧许可 → AFE → 时域/FFT/峰值
                                        ├← 同帧 measurement_valid
                                        └← HMI结束且UART最后停止位结束
同帧测量快照 → Board_Status_Display → BIN2BCD → 数码管扫描
事务状态/故障/模式 ───────────────────────────→ LED
```

模式、显示周期数和诊断视图在下一次测量入场时锁存；处理中拨动不改变本帧。AFE 保持 BRAM，直到本帧消费者和 UART 都结束，才准许下一帧。新增低后高释放资格检查，防止上一帧残留高电平提前释放新帧。

## 2. 开关与按钮

| 控件 | 行为 |
| --- | --- |
| SW3 / SW2 / SW1 / SW0 | C / B / A / 调试；优先级由左至右，全关默认 A |
| SW15=0 | 连续测量 |
| SW15=1 | 单次测量，上电或复位不自动测量 |
| SW14:4 | 预留，无功能 |
| BtnC | 系统复位（Basys 3 按下是高电平，虽端口名为 sys_rst_n） |
| BtnD | 请求一次测量；忙时最多排队一次，不累积多次点击 |
| BtnU | 请求切换 1/3 周期，下次事务生效 |
| BtnR / BtnL | 请求依次切换频率、Vpp raw、RMS raw、谱幅 raw；下次事务生效 |

单次保持状态下，BtnL/R 后需 BtnD 才会提交新视图。当前 UART 仍沿用原有 t0～t3 文本及波形协议；按钮不发送 page 命令，不能当作新屏幕工程已完成。

不要只凭拨杆向上/向下判断逻辑值。用户当前仅 SW1 与其余开关方向相反，下载后应见 LD[9:8]=00；若为 10 则选择了 C，应核对极性/位置。

## 3. 指示与单位

| LED | 含义 |
| --- | --- |
| LD0 | MMCM 锁定 |
| LD1 | 心跳，约每半秒翻转 |
| LD2 | 测量结果事件拉长约 100 ms |
| LD3 / LD4 / LD5 | 采集 / 算法 / HMI 忙 |
| LD6 | 当前结果有效且未过期；单次模式允许保持结果 |
| LD7 | 故障代码非零 |
| LD9:8 | A=00，B=01，C=10，调试=11 |
| LD10 / LD11 | 单次模式 / 三周期 |
| LD15:12 | 故障代码：1=超时，2=采集时 ADC 碰到码轨，F=非法状态 |

故障码保持到复位；码轨提示不等于已实现完整的模拟过载检测。采集前等过零超时可安全重试；已开始处理后超时不会强行覆盖消费者正在使用的 BRAM，允许迟到的完整事务退休，否则需复位排查。

默认数码管显示 kHz，一位小数：100 kHz 显示 `100.0`。无有效结果显示 `----`，整数超过四位显示 `OFLO`，不截断伪装成小数。Vpp/RMS/谱幅诊断视图均为 raw 整数，不是 mV。

连续模式下一次事务启动即取消上一结果的新鲜标志，因此数码管可能短暂显示无效；不能把它与采集停止混为一谈。当前 ILA 六探针保持兼容原抓取脚本，尚未增加 mode/frame_id 探针。

## 4. 可复现离线检查

```powershell
.\.venv-hds\Scripts\python.exe -m unittest discover -s scripts/contest -p 'test_*.py' -v
.\scripts\run_contest_sim.ps1
.\scripts\run_magnitude_scale_sim.ps1
.\scripts\run_behavioral_sim.ps1
```

第二条自动生成七组参考向量，再运行六个自检：事务控制、面板同步/消抖/扫描、AFE 帧所有权、小信号持续触发、独立三分量分析器、独立标定模块。日志在 `test_results/contest_sim`。参考模型使用量化窗/输入和浮点 FFT，不是 Xilinx 蝶形及 CORDIC 逐位等价证明。

第三条以实际生成的 CORDIC 网表验证 SignedFraction 30→31 位的 raw 增益，说明见 [参考模型与标度](contest_model.md)。数码管 Hz/100 使用 32 拍串行除法，并自检边界值、满 32 位输入和中途新结果重启，避免组合除法拉长 100 MHz 关键路径。

`scripts/setup_contest.tcl` 将四个 P2 控制模块注册进已有工程，不生成新 IP、不下载。P3 的 Component_Analyzer / Measurement_Calibrator 只独立测试，尚未替换顶层 Peak_Search 或提供物理标定系数；强谐波下的真实基频和≤5 mV 指标仍未验收。

## 5. 实板基线流程与待确认项

1. 信号源先关闭；核对新 bit 与 LTX 对应、实现时序和 DRC，再下载。
2. SW1=1，其余模式开关和 SW15=0；观察 LD0/LD1 及 LD9:8。
3. 使用已确认的高阻、100 kHz、100 mVpp、0 V 偏置正弦，读取多次新 ILA 事务；预期 bin=200、数码管 100.0，raw 值只与此前同条件比较，不标成 mV。
4. 关闭输出后改变模式；单次模式用 BtnD 触发，验证不会自行重复。不要在未确认量程前提高输出。
5. 每次记录源设置、SW、LED、结果、bit/LTX 散列；屏幕未接不填显示验收 PASS。

波形点数目前在顶层暂设 `WAVE_POINTS=240`。**用户需确认实际绘图区宽高，再修改显示参数并重建。** 屏幕整体240×320不能直接替代组件尺寸。合并远端`5e55cc4`后，最新目标为wave/fft双页面，各页曲线ID均为1；不再沿用单页spectrum ID2，尚待HMI迁移。

外部 AD9226 接口时序、模拟滤波器幅相误差、幅值标定、组合信号和屏幕两秒可见响应仍需独立验收。
