# 比赛验收现场操作手册

适用装置：Basys 3 / AD9226 / 模拟滤波器 / TJC3224T128_011；核对日期：2026-10-30。

本文是**待执行的操作规程**，不是验收通过报告。依据为仓库[赛题原文](requirements/2026年G题.md)和当前RTL。项目已约定不考核单路+5 V及屏幕至少6英寸两项，其余指标照常记录。正式评测以现场给定信号及启动/计时判据为准，文中的固定案例用于赛前彩排，不代替随机或裁判指定案例。

## 现场速查卡

1. **所有信号源输出OFF**，检查BNC/SMA锁紧、供电、共地、ADC位序/外部时钟和屏幕RX接线。
2. 核对通过时序的bit及匹配LTX，屏幕下载匹配的双页工程。**SW15先置1**，避免上电等不到过零而产生连续超时。
3. 设置A：仅SW1=1，SW0/2/3=0；按下松开BtnC，等待预热，保持源OFF。LD0亮、LD1心跳；**此时LD10可能仍灭，单次标志要到BtnD启动才生效**。
4. 源设100 kHz、100 mVpp、HIGHZ、0 V偏置正弦；确认后ON，再按BtnD。预期数码管100.0、无故障，屏幕显示新测量。
5. 按下文正式组合信号替换单音：每次**先OFF→配置/核对→ON→BtnD**。不要把旧保持帧当成新输入结果。
6. 默认视图从复位起：屏幕wave、1T。BtnU切3T，再按回1T；**BtnL一次请求fft，BtnR一次回wave**。保持态可重绘同帧，无需额外测量。
7. A/B/C各完成波形、参数、谱图、分量列表四项，并记录每项时间、误差和照片。C的目标是去干扰后的ub，不是总输入。
8. 收尾先关全部源输出、确认OFF，再保存记录和拆线。

## 1. 验收项目、人员和判据

建议一人操作信号源与接线，一人操作FPGA/记录；单人操作时也按“OFF—配置—核对—ON—测量”分开执行。比赛展示应以屏幕完成任务，ILA只作赛前排查和证据，不代替屏幕验收。

| 模式 | 被测组合信号总Vpp | 被测所有成分 | 附加条件 |
| --- | --- | --- | --- |
| A | 100～250 mV | 10～200 kHz | 基波+1或2个谐波 |
| B | 50～250 mV | 10～500 kHz | 基波+1或2个谐波 |
| C | ub为50～250 mV | ub的成分10～500 kHz | 再叠加uJ：200 mVpp、单频fJ≥1 MHz |

每种模式均需以下四项，每项完成时间≤2 s：

| 子项 | 检查内容 | 合格判据 |
| --- | --- | --- |
| 1 | 键控显示1个或3个完整周期 | 周期数/边界正确，形状稳定，无漏掉半周、截峰、旧帧混入 |
| 2 | Vpp、真RMS、基频 | Vpp和RMS各绝对误差≤5 mV；基频绝对误差≤1000 Hz |
| 3 | 正频率定性谱图 | 根数、相对频率位置、幅度比例大体正确，不把平顶窗主瓣当成多个分量 |
| 4 | 各分量幅值 | 按频率升序对应正确，每个正弦**峰值**幅度绝对误差≤5 mV；同时记录各分量频率 |

500 Hz是频率格点间隔；子项2的基频误差限值是1 kHz，不要混用。单音只检查链路，不能填正式A/B/C组合信号PASS。某一信号通过也不能外推整个范围通过。

原题说明7以相应信号源参数设置值作为标称值。预先明确源的负载显示约定和各分量单位，按裁判口径记录；示波器用于核对实际节点、负载和失真，**标称设置值与实际节点测量值分别保存**，不得测试后改用更有利的参考。现有系数仍是HIGHZ设定参考，非独立绝对输入校准。

### 新屏幕spec与当前bit的适配检查

撰写本手册期间已合并队友的`c57e2ff`屏幕spec，尺寸/ID/串口与当前RTL一致，但仍有下列差异，**不能直接宣称当前bit已完整匹配新屏幕**：

| 新spec | 当前RTL行为 | 上场前处理 |
| --- | --- | --- |
| tWaveXLeft/Mid/Right以us显示时间 | 当前只写Left/Right的0T与1T/3T，不写Mid | 补齐时间格式及中点，或先与屏幕方明确采用周期标签方案 |
| tFftYMid | 未发送中点幅值标签 | 按本帧幅值范围更新，不能保留示例常数 |
| tFftXMid；示例横轴0～200kHz | 当前横轴10～200/500kHz，不写Mid | 统一实际绘图区映射及全部刻度，避免静态100kHz与实际范围不符 |

中点控件即使存在也不会自动跟随其他文字更新。先确认差异已解决再进行带完整坐标的正式实屏验收；赛前仍可先做采集、数值与按键排查。本轮新增的是操作文档/离线向量，没有为这些差异修改RTL或生成新bit。

本规程不执行构建或控制仪器。250 mVpp边界、C干扰叠加及不同合路方式尚不能视为已有实测条件；实际执行前先核对各节点余量。使用脚本时，输出ON与上传用户槽均由操作者显式执行。

## 3. 接线检查：输出OFF、断电检查、上电复核

### 3.1 模拟链和阻抗

```text
普通A/B：信号源OUT ─BNC/SMA─> 滤波器输入 ─> 滤波器输出 ─> ADC模拟输入
                                                         ADC数字口 ─> FPGA
屏幕：FPGA JA1 TX ─> 屏幕RX，信号地共地
时钟：FPGA JB1 ─> ADC外部采样时钟输入
```

1. 在源面板确认OUT=OFF；使用双通道源时确认CH1/CH2都OFF，不只看电脑窗口。软件进程关闭不代表仪器停止输出。
2. 检查BNC卡口锁紧、SMA连接稳固、焊点无松动；滤波器PCB放在绝缘净空处，板底不压其他电路。当前系统曾因接头接触不良出现周期噪声，优先做这一步。
3. 核对滤波器方向和供电极性，再核对ADC模拟输入。滤波器输入已有约50 Ω并联终端，ADC模块输入约50 Ω，滤波器输出有约50 Ω串联电阻；**不要未经计算再加一个50 Ω终端**。
4. 记录信号源显示负载：现有参考使用HIGHZ。源自身输出内阻50 Ω、同轴特性阻抗50 Ω、菜单HIGHZ及装置实际负载是不同概念；改HIGHZ/50 Ω显示可能改变幅值解释，不是统一乘/除2的理由。
5. 有可接近的测点时，用高阻探头核对滤波器/ADC输入的幅值和削顶；探头机械倍率与示波器倍率一致。BNC/SMA同轴直连不是10×探头，通常应按1×通道倍率解释。
6. 若没有测点而需要暂时把ADC改接示波器，先OFF再拆线；记录负载已经改变。该测量仅作诊断，不能把未带ADC负载的输出当作原连接下的精密参考。恢复后重新核对接头。

### 3.2 数字链、屏幕和时钟

| 检查项 | 接线/预期 |
| --- | --- |
| ADC时钟 | FPGA JB1/A14 → ADC外部时钟输入；不得与模块振荡器输出硬并联 |
| ADC bit0～6 | JB2/A16、JB3/B15、JB4/B16、JB7/A15、JB8/A17、JB9/C15、JB10/C16 |
| ADC bit7～11 | JC1/K17、JC2/M18、JC3/N17、JC4/P18、JC7/L17 |
| 屏幕RX | FPGA JA1/J1 → 屏幕RX；屏幕TX不接FPGA |
| 地和逻辑 | FPGA/ADC/屏幕参考地可靠连接；ADC输出电平兼容FPGA 3.3 V I/O |
| 屏幕供电 | 按屏幕模块规格，不能默认由PMOD 3.3 V脚供整屏 |
| 串口 | 115200、8N1；不要让另一个USB-TTL TX同时驱动屏幕RX |
| 波形组件 | wave页/fft页各ID=1、通道0；默认有效绘图区240×160 |

bit0为模块总线最低位，不能把ADC芯片手册里的BIT1名称直接当作bit0。接线以实际模块标注及[XDC](../sources/constraints/Basys3_Pinout.xdc)为准。

## 4. 上电、下载和100 kHz基线

### 4.1 启动顺序

1. 所有源保持OFF。SW15=1；SW1=1；SW0/2/3=0，SW4～14预留置0。
2. 启动信号源，确认输出仍OFF；按设备要求给模拟前端、ADC、屏幕、FPGA供电，核对各电源指示。
3. 如用JTAG，操作者在Hardware Manager下载已通过实现的bit及匹配LTX；如用Flash，确认加载的是本轮镜像。不要把JTAG配置时间混入一个自行定义的2秒测量计时。
4. 按住BtnC约0.1～0.3 s后松开，等待约1 s用于赛前准备。LD0应亮，LD1应心跳，LD7应灭。测到JB1约4.096045 MHz。没有ADC时钟或电源异常时，不进入后续测量。
5. 复位后初始为频率视图、wave页请求、1T请求。因为还没有测量，数码管应为`----`；屏幕尚未有新包时可保留其上电页面，不要求立即收到新文本。

SW15虽已置1，LD10在首次BtnD前可能灭，这是single_active尚未锁存，并非立即判定开关反接。单次等待时没有捕获许可，不应仅因OUT=OFF而强迫复位重试。

### 4.2 信号源正弦设置

在源面板或已验证脚本中设置：SINE、100000 Hz、100 mVpp、0 V偏置、HIGHZ；关闭调制、扫频、突发等额外功能，另一输出通道保持OFF。先读回/拍照核对，再开启指定通道OUT。

按一次BtnD，等待新结果：

| 观察 | 预期，不等于已测结果 |
| --- | --- |
| 模式/状态 | LD9:8=00，LD10亮；LD3～5只在相应阶段忙，LD7无故障 |
| 板载数码管 | 100.0，表示100.0 kHz；raw视图不是mV |
| 新屏幕wave | Vpp约100.0 mV、RMS约35.4 mV、f1约100000 Hz；波形正负方向正确 |
| 新屏幕fft | 一条100 kHz分量，峰值幅度约50.0 mV，其他分量槽为`--` |
| ILA（需要时） | 新probe0事件，bin约200、count=1、校准启用；默认系数epoch=0有效 |

如果数字正常但波形方向相反、尺寸滚动或控件不更新，先按屏幕契约诊断，不现场改ADC位序/拟合增益来补偿界面问题。基线不通过，不进入正式组合信号测试。

## 5. 任一新信号的标准操作循环

每换一个测试点，照以下顺序，尤其适用于单次模式：

1. **OFF**：关闭相关源输出，确认面板OFF。
2. **配置**：选对应信号/谐波/相位/总幅值和负载；设置FPGA模式开关。单次模式只请求切换，旧模式LED可能要到下一次BtnD才改变。
3. **核对**：记录各Ui到底是peak、Vpp还是RMS；检查频带及总Vpp在所选模式范围内。
4. **ON**：开启唯一计划输出，等待源设置稳定。这里的赛前稳定等待不能用于隐去正式启动计时。
5. **测量**：按一次BtnD并记录计时起点；以新frame_id确认，或在不接ILA的展示中结合LD2新结果脉冲、已知输入变化及完整刷新判断。仅按过按钮或数字恰好相同不能证明读到了新帧。只更改源不按BtnD，单次模式本来就应保留旧值。
6. **展示/记录**：先wave的1T、3T及数值，再fft的谱图和各分量；逐项保存时间、读数和照片。
7. **下一点**：先OFF再配置。若保持态重绘完成而源已改变，仍需BtnD才能用于新点判定。

### 5.1 按键速查与已知界面边界

| 目的 | 从复位初始状态的操作 | 判断依据 |
| --- | --- | --- |
| 新测量 | BtnD一次 | 新frame_id；不是只看UART还在发送 |
| 1T→3T→1T | BtnU一次、再一次 | wave的tWaveSpan和实际周期数；保持态LD11可能仍是上次事务标志 |
| wave→fft | BtnL一次 | 页面变fft，分量列表和曲线完整 |
| fft→wave | BtnR一次 | 页面回wave，保留本帧1T/3T请求 |
| 重置到已知视图 | BtnC，重新取一帧 | 频率视图、wave请求、1T；同时恢复默认bank |

左右键请求顺序：频率(0)→Vpp raw(1)→RMS raw(2)→谱幅raw(3)→频率。只有请求3对应fft，其余都对应wave。若中途多按过键，不能机械套用“左一次就是fft”；先根据当前页/已知请求判断，必要时在输出条件安全时复位再测。比赛计时过程中不要用复位掩盖失败。

板载诊断view和LED周期位在下次测量事务入场锁存；屏幕在HOLD可按请求重绘，因此保持态二者可以不同步。`OFLO`仅表示raw整数超过四位数码管，不自动等同于ADC削顶；码轨故障看LD7和错误码。

## 6. 组合信号怎么设，参考值怎么算

正式信号写成`u(t)=Σ Ui·sin(2πhi·f0·t+φi)`，Ui为mV **peak**，hi包含基波1和一个/两个谐波。

- 若源菜单用Vpp：每分量输入`2Ui`；若用RMS：输入`Ui/√2`。不要把总Vpp填给每一个分量。
- 合成波总Vpp为`max(u)−min(u)`，不能简单相加各分量Vpp；相位改变会影响总Vpp。
- 零均值整数谐波组合的整周期参考RMS为`sqrt(ΣUi²/2)`。有限8192点记录与模拟链有偏差，应按既定误差限值判断。
- 基频是最低可信的基波，不是最大幅度那根谱线。

### 6.2 用现有UTG932准备A/B波形（可选，赛前完成）

[彩排向量目录](acceptance_vectors/README.md)提供上述A/B的JSON计划。它们的`tones[].vpp`单位为V、表示**各分量Vpp**，不是本表Ui；顶层`vpp`是±1样本对应的满量程。生成采样表只用电脑离线计算：

```powershell
# 在仓库根目录；保存目录需先存在，目标文件不得已存在。
New-Item -ItemType Directory -Force test_results/acceptance | Out-Null
.\scripts\utg932.ps1 multitone docs/acceptance_vectors/A_THREE.json --save test_results/acceptance/A_THREE_samples.json
.\scripts\utg932.ps1 arb test_results/acceptance/A_THREE_samples.json --channel 1 --slot 1 --name AcceptA --dry-run
```

确认要覆盖的用户槽已备份、所有输出OFF、A_THREE幅值在硬件余量内后，由操作者执行上传，**结束仍OFF**：

```powershell
.\scripts\utg932.ps1 arb test_results/acceptance/A_THREE_samples.json --channel 1 --slot 1 --name AcceptA
.\scripts\utg932.ps1 status --channel 1
# 核对物理接线及面板设置后才执行；ON会在脚本退出后持续。
.\scripts\utg932.ps1 output on --channel 1
# 测试完毕：
.\scripts\utg932.ps1 output off --channel all
```

A_THREE的整表重复频率应为10.5 kHz，顶层满量程为200 mVpp，而合成波理论总Vpp约137.041 mV。两者不同是归一化定义，不应把它“修正”成200 mV的测量目标。换文件时重新核对重复频率、幅度、相位、HIGHZ、偏置和OFF；确认另一通道OFF。源的实际带宽、ARB插值/量化仍须在接入FPGA前核对，不能仅凭JSON正确认定物理波形正确。

没有可用ARB或谐波合成源时，只完成单音链路检查，正式组合验收记“未测”；不以方波的不可控高次谐波代替指定组合。

### 6.3 若现场改用AFG1022

仓库另有[AFG1022操作说明](afg1022_automation.md)。本机已验证身份/配置回读，但ARB实机上传和实际端口输出仍未验收，不能直接把它当成已通过的比赛信号源。先完成源本身的波形/幅值核验，再接本装置。

可使用6.2离线生成的同一`A_THREE_samples.json`，但**AFG脚本不自动采用JSON输出元数据**。示例只供操作者在核验后执行，本文没有执行：

```powershell
.\scripts\afg1022.ps1 arb test_results/acceptance/A_THREE_samples.json --channel 1 --hz 10500 --vpp 0.2 --offset-v 0 --load HIGHZ --dry-run
# 确认允许覆盖两路共享的易失编辑内存EMEM后，移除--dry-run上传；结束仍OFF。
# 开启时必须重新完整指定参数：该入口会先重配，不是单纯沿用面板设置！
.\scripts\afg1022.ps1 output on --channel 1 --waveform arb --hz 10500 --vpp 0.2 --offset-v 0 --load HIGHZ
# 收尾分别关闭：
.\scripts\afg1022.ps1 output off --channel 1
.\scripts\afg1022.ps1 output off --channel 2
```

没有完成上传/回读时不要直接执行上述ON。不要将UTG的`output on --channel 1`简写照搬到AFG，否则可能使用脚本默认波形/频率而覆盖ARB设置。不同源的负载显示、幅值、直流偏置均重新核对，不沿用历史面板值；更换源后的默认系数一致性也要复测。

## 7. A、B模式逐项演示

### A模式

1. 使用A_THREE，所有输出先OFF；设置仅SW1=1，SW15=1，SW0/2/3=0。设置好源后ON，BtnC回初始请求，再按BtnD取新帧；正式计时按第9节选定起点，不把准备等待算作“已经完成”。
2. **A1**：wave页确认1T完整波形，再按BtnU显示3T，最后按回1T。检查不截负半周、不滚走首部、端点/周期数正确，记录两次切换时间及照片。
3. **A2**：记录Vpp、RMS、f1。A_THREE参考137.041054 mV、47.169906 mV、10500 Hz；计算三项有符号误差，按绝对值判定。
4. **A3**：从初始请求0按BtnL，确认fft页三根谱线在10.5/31.5/42 kHz附近，相对高度约60:25:15。A页固定10～200 kHz横轴使三根线靠左是合理现象，不为“看起来稀疏”改变频率。
5. **A4**：逐槽读频率/峰值幅度，目标60/25/15 mV；按频率配对后再算误差。1个基波+2个谐波是三根线，不要求它们必须是1、2、3倍频。
6. 关闭OUT，换A_TWO核对两分量/第三槽清空，换A_HIGH检查200 kHz上界，再做100/250 mV总Vpp边界。每个新点都按第5节重测。

### B模式

1. 输出OFF，设置仅SW2=1，SW15=1；选B_HIGH后ON，按BtnD，确认LD9:8=01。若想回初始页/1T，可在正式计时前复位并重新测量。
2. **B1/B2**：wave的1T/3T及参数，参考68.520527 mV、23.584953 mV、125000 Hz。
3. **B3/B4**：fft横轴上限500 kHz，三根线125/375/500 kHz，峰值30/12.5/7.5 mV。边界500 kHz在最右侧，必须保留，不能因像素抽样漏掉。
4. 再做B_LOW、B_WEAK、B_PHASE、B_OFFGRID及50/250 mV总Vpp边界；每组记录四项与时间。B_WEAK验证基频选择，B_PHASE验证真RMS/非对称波形，B_OFFGRID验证泄漏/量化误差。

250 mV、低幅弱基波及最高频组合可能暴露尚未验收的问题，失败应原样记录；不靠临时更改增益、门限、频带或参考值补成PASS。

## 8. C模式：加干扰后的完整流程

**C开关只选择处理模式，并不会自动在输入端产生干扰。** 当前C测试尚未完成实板验收。先完成B同一ub基线，再加uJ，期间固定校准bank；频率/幅值目标始终属于ub。

### 8.1 先确定合成方法

优先使用可同时合成ub与uJ的单输出源，保持同一电缆和输入终端。若用两路输出，必须经已验证的合路器/求和电路，考虑衰减、隔离和负载；**不能直接把两个源OUT用T头并联**。若合路器未准备好且没有已核验的单输出复合波，C记“未测”，不能凭滤波器理论响应填通过。

一个便于单输出ARB准备的数学案例是：

```text
ub = 30 sin(2π·125k·t) + 12.5 sin(2π·375k·t) + 7.5 sin(2π·500k·t) mV
uJ = 100 sin(2π·1000k·t) mV
u  = ub + uJ
```

整表重复频率125 kHz，谐波阶数1、3、4、8；用1000点表时数学上可表示。归一化可取`x[n]=(30sinθ+12.5sin3θ+7.5sin4θ+100sin8θ)/150`，源满量程设300 mVpp、零偏置。**300 mVpp是ARB满量程，不是ub的Vpp或输入实际总Vpp**；实际输入最坏峰峰值上界约268.521 mV。此幅度超出此前100 mVpp试验包络，先核对前端和ADC余量。

当前A/B `utg932.ps1 multitone`明确限制各音调≤500 kHz，**不能直接给它塞入1 MHz干扰，也不要改小fJ绕过检查**。C需在具备相应能力的源/波形编辑器中制作并核验，或另行准备经过审查的采样表。文中数学可表示不等于已验证UTG的实际ARB高频输出质量。

### 8.2 C基线与加入干扰

1. 全部输出OFF，接好确定的合成链路，设置仅SW3=1，SW15=1，SW0/1/2=0。
2. **只输出ub**，重测并记录C/无干扰基线：Vpp约68.520527 mV，RMS约23.584953 mV，f1=125 kHz，各峰30/12.5/7.5 mV；完成四项展示。
3. 先OFF，再**只保留uJ**检查其标称200 mVpp、fJ=1 MHz、0偏置；用合适示波器/频谱检查源与输入节点。两源合路时，另一端口必须处于合路器规定的终端状态，不能用“拔线”任意改变负载。
4. 在输出OFF时恢复ub+uJ，核对各分量幅度没有因重新归一化/合路衰减而改变。尤其单输出ARB应保持相同的幅值换算，不能“添加干扰后自动归一到100 mVpp”。
5. 检查总输入不会使滤波器或ADC削顶，开启输出，按BtnD获取新帧；确认LD9:8=10。若碰码轨或形状失真，先OFF并排查，不能仅调低uJ后仍标200 mVpp通过。

### 8.3 C1～C4判定

- **C1**：wave页应恢复ub的1/3周期形状，不以细密1 MHz波纹为合格，注意与同一ub无干扰基线对照。
- **C2**：仍与ub的68.520527 mV、23.584953 mV、125 kHz比较，分别≤5 mV、≤5 mV、≤1 kHz。不是只计算“加干扰前后差”；前后都可能同向偏离标称。
- **C3**：谱图应体现ub三根线的相对位置和比例。显示范围本来就到500 kHz，**看不见1 MHz并不能证明干扰被抑制**，还需C2/C4通过且不削顶。
- **C4**：125/375/500 kHz各峰仍应接近30/12.5/7.5 mV，逐分量误差≤5 mV；不把干扰泄漏的新低频峰当成ub谐波。
- 四项计时按与A/B相同的可见完成定义进行。至少记录指定fJ点；若评测改变fJ/相位/ub幅值，每次按标准循环重测，不能把1 MHz一点通过推广为所有fJ≥1 MHz。

采样约4.096 MSPS，超过Nyquist的干扰可能折叠进被测通带。例如约3.996 MHz可折叠到约100 kHz，单靠ADC之后的数字低通不能分辨这种混叠；需要模拟链抑制并实测。C验收时按实际指定干扰频率核验，不擅自缩小原题范围。

## 9. 两秒响应怎么测、怎么留证据

使用能同时拍到操作者动作、源状态、FPGA和屏幕的视频。短按需超过20 ms消抖时间，可按约0.1～0.2 s后松开；计时从规定的物理动作开始，**不能从软件debounce之后或串口最后字节开始计时**。

| 场景 | 起点记录 | 终点记录 |
| --- | --- | --- |
| 冷上电/正式启动 | 电源/启动动作及裁判认可的定义 | 要求的参数/整条曲线实际可见且完整 |
| 复位启动 | 松开BtnC | 新结果可见完整 |
| 单次新测量 | 按下BtnD | 对应新帧参数/完整曲线可见 |
| 切页 | 按下BtnL/BtnR | 目标页文本及整条曲线完成，无旧点残留 |
| 1T/3T切换 | 按下BtnU | 标签及完整1T/3T曲线一致更新 |

对正式“启动装置后≤2 s”的解释先与评测判据一致；冷启动、按键启动、切页分别记原始时间，不能用较快的切页数据替代冷启动。双页展示的人为等待如何计入也应明确，不自行设定豁免。JTAG人工下载是准备动作；若以断电启动验收，应提前验证Flash自启动，而不是把下载完成当作上电时刻。

测曲线要看最后一个点/完整波形，不能只看第一点或数字先更新。ILA的measurement事件、FPGA latency_cycles、UART线路估算只辅助定位，均不能代替屏幕完成时间。超过2 s、旧帧误读、形状不完整均单独记录，不能因数值准确就给该项PASS。

## 10. 连续/单次、复位与故障恢复彩排

正式四项之外，再做操作可靠性：

1. **单次保持**：取100 kHz帧后把源改为另一已确认频率，不按BtnD应保持旧值；按BtnD才更新。保持态切页/周期应仍属同一frame_id。
2. **连续**：SW15=0，在新事务生效后LD10灭；改变源后自动更新，不需复位。回SW15=1后等待事务安全收尾，再用BtnD重测。
3. **关闭/恢复输出**：连续模式观察自动更新；单次模式OFF后本来应保持旧帧，须按BtnD才请求重测。确认新无效帧会清除旧数值/曲线；若没有过零导致超时，记录LD7/故障码及旧值保持/过期表现，不能伪称它已经测得零信号。
4. **复位**：事先记录在线系数；BtnC会恢复默认bank、epoch=0、初始页请求和1T。VIO保留的旧请求不应自动重放。需要新系数时按完整原子提交流程重新设置。

| 现象 | 优先检查和处理 |
| --- | --- |
| LD0不亮/ADC无时钟 | FPGA供电、正确bit、复位未按住、MMCM锁定、JB1接线 |
| LD7亮、LD15:12=1 | 过零/ADC电源/数据是否更新，还是算法/显示超时；拍下现场再复位，故障码可能保持 |
| 错误码2 | 采集碰码轨；先OFF，核对输入余量、偏置和位序，不把它当作完整过载测量 |
| 数字一直不变 | SW15是否单次、是否按BtnD、是否仍在看旧ILA capture；不要把正常HOLD当死机 |
| 幅值相差约2倍 | 源HIGHZ/50 Ω显示、实际终端、额外50 Ω、峰值/Vpp定义和探头倍率；不要先盲改RTL系数 |
| 波形阶梯/抖动/截峰 | 接头/底部短路/模拟削顶、真实ADC点数与插值极限、屏幕尺寸/Y方向、周期估计和相位对齐 |
| 频谱页无峰或槽错位 | 是否新帧、模式频带、count、频率排序、ID/页面匹配；弱基频/非整频边界如实记录 |
| 屏幕无数据但ILA正常 | RX接线、共地、电平/波特率、新控件名、曲线ID/实际绘图区、页面策略；屏幕TX不接不会使FPGA等待ACK |
| USB查询失败/OFF不确定 | 在仪器面板手动关闭输出并核对，再处理连接；不把脚本退出当作已关输出 |

更改接线/供电前先OFF。遇到故障不要同时换线、复位、改系数、改源设置；一次改一个条件并记录，避免失去故障证据。未排除的失败停止该测试项，不通过复位反复挑一帧填PASS。

## 11. 记录、判定和收尾

每个新输入至少保存两次独立新测量，用于检查重复性，不只是重复拍同一HOLD帧。视频/截图与结果表关联到case、bit、源设置和活动epoch。误差定义：

```text
ΔVpp = 显示Vpp − 标称Vpp
ΔRMS = 显示RMS − 标称RMS
Δf1  = 显示f1  − 标称f1
ΔUi  = 按频率配对的显示峰值Ui − 标称峰值Ui
```

取绝对值与限值比较。数值、波形、谱图、时间分别判定，再汇总A1～C4；“未测/受条件限制”不写PASS。参考换算、ILA读数和屏幕读数分列，不拿电脑离线换算补填屏幕实测。

收尾顺序：所有源OFF并在面板确认→必要时拍OFF状态→保存记录/视频/源波形表及版本→切断输出后再拆线/断电。最终记录只描述实际操作，不沿用历史“源已关闭”状态。
