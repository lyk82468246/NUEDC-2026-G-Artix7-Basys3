## 实现行为

| 项目 | 当前RTL |
| --- | --- |
| wave横轴 | 每帧更新tWaveXLeft、tWaveXMid、tWaveXRight，单位us；另保留tWaveSpan的1T/3T |
| 时间精度 | 一位小数，按当前帧的500Hz-grid f1计算，不是固定示例，不受电压校准是否启用影响 |
| fft横轴 | A为0/100/200kHz，B/C及调试显示为0/250/500kHz；三个刻度全部更新 |
| fft像素 | 与上述0起点/上限使用同一映射；分析器的最低检测频率仍是原10kHz等规则，没有扩大被测频带 |
| fft纵轴 | tFftYTop为范围内最大分量的校准峰值，tFftYMid为其一半，tFftY0为0 |
| 默认页面发送 | DISPLAY_PAGE_REFRESH=1，每批先重申选定页并等待切页间隔，再更新全部文本/刻度、cle、W个add；不自动切到另一个页 |
| 兼容参数 | 仍可显式将DISPLAY_PAGE_REFRESH改为更大值或0以稀疏重同步，但不属于本次spec默认行为 |
| 缺失/无效 | 无有效频率时中/右时间刻度为--，左端仍0us；无有效标定或溢出时电压刻度为--，不假造mV |

默认INVERT_Y=0、W=240、H=160，wave零位80，fft基线0，Y全在0～159。非默认翻转配置保留回归，但不是“默认零位80”这一固定约定的等价配置；实屏方向仍需核对。

## 数学、握手与资源约束

设C为1或3：右端时间=`C×10^6/f1` us，中点=`C×10^6/(2f1)` us。串行除法直接计算0.1us单位：`round_half_up(C×10^7/(d×f1))`，d为1或2，再复用BIN2BCD逐字节输出小数点/末位。只舍入一次，不先近似周期再乘3。

分母、常量分子、半入加法和除法请求分拍；新增一个现有模块类型的48位迭代除法实例，没有新IP、时钟域、整帧RAM或变量乘法。保留已有逐字节命令组装和分组复位，不重新引入宽组合字符串移位。实际DSP/LUT/时序以用户下一次实现为准。

fft半量程在uV中间精度采用右移取整，然后按0.1mV显示舍入，与`round(full_uv/200)`等价。例如满量程99uV时，半量程49.5uV应显示0.0mV，不能先向上取50uV又舍入成0.1mV。

同帧raw、gain、epoch、频率与周期请求仍冻结到批次结束；HOLD重绘不产生新测量。像素ready/valid、UART最后停止位和frame_release契约保持原样。时间刻度仍依据格点频率，并未解决亚bin周期估计或复合波相位锁定。

## 端到端UART验证

`run_display_hmi_sim.ps1`三组测试顶层均直接解码UART线：短帧、完整8192点/240像素、Y翻转/非默认稀疏页面策略。每组17个完整批次及1个复位中断批次，比较所有命令、像素、FF结束符和STOP/释放。

| 频率 | 周期数 | 中点us | 右端us |
| --- | --- | --- | --- |
| 10kHz | 1 / 3 | 50.0 / 150.0 | 100.0 / 300.0 |
| 100kHz | 1 / 3 | 5.0 / 15.0 | 10.0 / 30.0 |
| 10.5kHz | 1 / 3 | 47.6 / 142.9 | 95.2 / 285.7 |
| 500kHz | 1 / 3 | 1.0 / 3.0 | 2.0 / 6.0 |
| 2MHz数字格式边界 | 1 / 3 | 0.3 / 0.8 | 0.5 / 1.5 |

2MHz只用于验证亚微秒/半入格式，不宣称模拟链或完整波形测量支持该频带。其余覆盖未加载系数时仍有时间标签、无信号清除、0起点谱图端点/每像素、中点幅值舍入、HOLD、在线参数变动不混帧、复位和最后停止位。

准备模块3组、快照/实际板级接口2组，以及116项主机测试通过；本轮合计8组XSim顶层。厂商DSP顶层仍使用黑盒，不是完整ADC→FFT数值仿真。日志归档在[适配回归](../reports/screen_spec_20261030/README.md)。
