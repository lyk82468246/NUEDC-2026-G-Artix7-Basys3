# 实屏反馈：频谱方向、文字刷新与频率格式

> 后续高频绘图改为16抽头/64相位带限插值，见[修订说明](waveform_interpolation_20261030.md)。本文的两点插值/起点细节仅描述此前版本；刷新及同帧规则继续沿用。

日期：2026-10-30。此次只修订源码及离线仿真，用户负责后续综合、实现和烧写。

## 1. 频谱左右镜像

原RTL的逻辑坐标为`x=round(f×(W−1)/fmax)`，发送顺序为逻辑x从0到W−1。
用户观察到整幅谱线左右镜像，而静态刻度正确；这与屏幕把较新的add点放在右侧、旧点向左移动相符。
这是根据源码和实屏现象作的接口方向判断，尚未读取最终HMI工程的控件属性，不能断言它由哪一项屏幕属性造成。

修订增加顶层参数`DISPLAY_FFT_REVERSE_X=1`，在频谱renderer中按逻辑x从W−1到0发送，
但串口流序号仍从0到W−1，结束/握手不变。这样适配本次反馈的屏幕行为，使最终画面低频在左、高频在右。
频率值、文本刻度和FFT索引不反转；没有新增整幅缓存。若以后改变屏幕滚动方向，设该参数为0，避免两端同时补偿。

上机验证请使用A模式50kHz和150kHz单音，分别应出现在屏宽约1/4及3/4处。
100kHz恰在200kHz量程中间，不能检验左右方向。B模式可用125kHz和375kHz作同样检查。
wave页本轮未改变时间方向；若采用相同控件滚动方式，也可能存在时间镜像，后续需用非对称复合波形核对，单音正弦不能充分区分。

## 2. 文字什么时候更新

RTL没有“基频变化才更新文字”的条件。连续模式每个完整测量帧都更新该页全部测量文字、刻度和曲线，
即使频率不变而幅值变化也会更新。单次HOLD保留原帧，必须新触发才有新测量；切页/跨度可重绘旧帧。
幅值、频率、波形和gain/epoch均为同帧快照，当前不会独立异步刷新某个幅值。

旧顺序先发送240点，再写文字，最后只显式`ref 1`曲线并`ref_star`。
所以至少存在一批串口绘图的等待时间；另外某些固件在暂停刷新期间对文字赋值后，可能需要显式ref该文字控件。
实屏“某些参数不及时”的具体原因尚需新版本确认，不能仅凭源码断言必为固件缓存。

当前每次`.txt=`完成后追加`ref 控件名`，仍保留曲线暂停刷新、同页不重复page以及UART完成后释放源帧。
ref指令复用原有逐字节构建器，避免动态长度编码和512位可变移位串成新的组合路径。
这会增加少量串口时间；不会让采集率等同于显示更新率，也不会消除整批发送的固有等待。
若仍有个别文字不更新，应检查屏幕控件名、文字容量以及页面定时器/事件是否覆盖了FPGA写入值。

## 3. 频率显示格式

wave及fft页的分量频率统一显示一位小数kHz：

| 原值 | 新文字 |
| --- | --- |
| 10000Hz | 10.0kHz |
| 10500Hz | 10.5kHz |
| 135000Hz | 135.0kHz |
| 135500Hz | 135.5kHz |
| 500000Hz | 500.0kHz |

利用Hz数值的BCD高位作整数kHz，第2位作0.1kHz位，无新增除法器或DSP。
测量链路输出为500Hz格点，所以小数位通常为0或5；不意味着测量精度提高到100Hz。
500Hz是格点间隔，实际频率误差仍须实测。raw、频率Hz内部值、ILA和标定系数不变。
无效分量仍为`--`。轴端点文字仍为0/100/200或0/250/500kHz。

## 5. 下一阶段：先标定，再用真实谐波验收

1. 烧写本轮版本后，用上述非中点单音核对方向；频率固定、只改幅值，连续模式下确认文字和曲线都能更新。
2. 保持信号源→滤波器→ADC→FPGA的最终链路。先在100kHz采集多个幅值点的Vpp raw、RMS raw、FFT raw及同帧有效性/epoch。
3. 尽可能测系统输入端实际Vpp，保持原输入负载不变；示波器额外50Ω终端会改变负载。仅用发生器设定值时，结果继续标注“发生器设定值参考”，不能作为独立绝对精度证明。
4. 正弦的参考峰值为Vpp/2、RMS为Vpp/(2√2)。分别拟合Vpp、RMS及FFT峰值的uV/raw系数，检查线性和截距，不能把三种raw单位混用。
5. 使用VIO在线试系数，另取新帧核验；固定幅值扫10～500kHz检查链路频响，不能用100kHz一点代替全带宽标定。确认后才更新默认RTL bank。
6. 再用已核验的任意波信号源做真实三分量、弱基波/强谐波、非整频和改变初相测试，分别验收分量峰值、总Vpp、总RMS与复合波形；最后进行C模式干扰叠加。

详细现场操作沿用[验收手册](contest_acceptance_runbook.md)和[AFG1022波形方案](afg1022_acceptance_waveforms.md)。
此次未操作信号发生器、未连接JTAG或采集新的实板数据。
