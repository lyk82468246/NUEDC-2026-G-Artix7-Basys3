## 模块与接口契约

| 模块 | 功能 | 关键契约 |
| --- | --- | --- |
| Display_Unsigned_Divider | 参数化无符号串行除法 | 单请求在途，valid/ready；分母0也完成，显式错误及全1商 |
| Display_Frame_Calibrator | Vpp、RMS、三个分量峰值、波形Amax转参考µV | 同拍锁存raw/gains/frame_id/epoch；六字段共用一个乘法运算单元；结果整体发布 |
| Display_Wave_Renderer | 同步BRAM整帧Amax扫描、分数地址线性插值、归一化波形点 | 8192深度默认；W/H参数化；BRAM必须被冻结直到该帧消费结束 |
| Display_Spectrum_Renderer | 最多三分量的谱线点流 | 不是等距抽FFT bin；频率位置舍入到像素，合并取最大并标记碰撞，范围外剔除并标记 |
| Display_mV_Formatter | µV→一位小数mV的ASCII流 | 50µV半入舍入，无效为--；不包含控件名、单位或FF结束符 |

输入/输出均在同一算法时钟域，外部需先完成CDC。输入valid和ready同拍才接收；忙时无输入队列，生产者必须遵守握手，不能丢入一个未获ready的measurement脉冲后假定已经接收。输出valid在ready到来前保持数据和last/index/tag不变。

### 数值快照与校准

增益采用已有无符号Q16.16“参考µV/raw”。Vpp及Amax用vpp_gain，RMS用rms_gain，三个正弦峰值用fft_gain。三个分量按上游频率升序，低位槽0；频率由bin×500得到Hz。

乘法使用完整64bit，再以65bit加32768半入舍入，右移16并饱和到uint32。任一字段饱和会报告overflow并撤销voltage_valid。未加载系数或零增益不得冒充校准电压：数值字段为0、voltage_valid=0，文本格式器应显示--，而不是0.0mV；有效信号的频率/分量数仍可保留。无信号则频率和分量槽也清零，所有情况都产生完成包，不死锁。

内部converted数组不直接暴露，PUBLISH阶段才整体更新公开结果。输出背压期间不可被下一帧覆盖。loaded/valid只表示系数配置有效，不证明输入端绝对电压已独立校准；目前系数仍是发生器设定参考。

**集成时必须先锁存测量事件对应的raw、三个增益、epoch和frame_id，之后再等待波形扫描得到同frame_id的Amax。不能在Amax扫描完成后临时读取live VIO增益，却给结果贴上旧epoch。** 这个事件收集/BRAM仲裁控制器将在最终spec及页面策略确定后接入，本轮没有把模块直接接到现有事件上。

### 波形坐标

采用估计基频的完整1/3周期跨度，而不是先floor(N/bin)再乘周期数减1：

```text
sample_position(p) = p * C * N / ((W-1) * bin), C=1或3
p = 0..W-1，Q12分数地址，末点包含重复的周期端点
```

同步BRAM读第一个和相邻样本，做有符号差分线性插值。负数插值移位向负无穷取整，误差小于1 raw LSB；不改变上游Vpp/RMS/FFT计算。-32768绝对值以扩展位处理，Amax是无符号16bit，可表示32768。跨度超过BRAM末点则夹到最后样本，并报告window_clamped，不环绕读错帧。

先扫描整帧计算Amax，axis_valid脉冲发布稳定的amax_raw及frame_id；随后输出W个pixel点。默认H=160，逻辑零位为80，正负满量程为159/1（对称映射保留一个底部像素）；所有值都在0..H-1。逻辑值“越大越正”，**不假定TJC的add数据上下方向**；最终适配层按实屏约定决定是否翻转。无信号、bin0或Amax0均安全输出中线且plot_valid=0，不除零、不沿用旧波形。

这里只修复整数跨度截断，仍依赖输入的500Hz-grid基频估计。真实非整频周期估计、复合波多次过零引起的相位对齐、模拟波形精密重建仍未解决；线性插值不会凭空增加ADC信息，不可称“任意信号已完整稳定显示”。

### 频谱坐标

对每个检测分量，把(f-fmin)/(fmax-fmin)映射到0..W-1，幅值按当前范围内最大分量映射到0..H-1，均做无符号半入舍入。支持A的10～200kHz或B/C的10～500kHz等外部配置，范围在输入握手时锁存。

每帧发送恰好W个点，峰值所在像素输出归一化高度，其余0。两分量同像素取最大值并报告collision，不声称屏幕能分开显示；范围外分量不夹到边缘制造假峰，报告out_of_range。非法范围或没有有效分量输出W个0，plot_valid=0。scale_raw在axis_valid时有效；collision在首个pixel前计算完成，window/范围等诊断以该帧结束状态为准。

这是已检测分量的定性谱线图，不显示全部4096bin噪声底，不能掩盖上游漏检。源文本幅值仍由完整分量列表生成，不从像素反算。

### 文本及显示帧所有权

格式器输入uint32参考µV，输出数字正文：123456→123.5，0→0.0，50→0.1，0xFFFFFFFF→4294967.3，无效→--。输出有byte_valid/ready/last；mV单位、引号、控件名和三个FF必须由后续协议层补齐。

renderer的done仅表示最后一个像素被下游接收，formatter的done仅表示最后一个数字字节被接收，**都不代表UART最后停止位或屏幕执行结束**。不得直接用它们替换Run_Controller的packet_finished或释放BRAM。最终事务控制器须保持同帧数据到显示批次/UART完成，并明确单次保持与切页重绘策略。
