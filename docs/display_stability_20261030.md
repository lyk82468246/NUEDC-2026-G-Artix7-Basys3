# 复合波形的稳定显示与刷新事务

日期：2026-10-30。本文取代旧适配记录中的“每批重复page”默认策略。
本轮只修改源码、注册工程并执行离线仿真；没有综合、实现、生成bit或下载。

## 显示目标与数据来源

显示的是AFE滤波、去直流后的**完整复合采样波形**。基波仅用于确定周期和相位参考，
不会用基波正弦替换采样数据，也不会通过三条FFT谱线重建曲线。
因此含谐波时，画面应保留畸变、多个局部峰和非对称正负峰。

基波正向过零相位作为横轴起点，复合信号本身在该点不一定等于零。
横轴0表示相对触发起点，不表示整帧BRAM地址0。显示1T或3T，最后一个像素包含周期终点。
这是一帧接一帧的触发显示；没有将采集空隙伪装为连续滚动波形。

## 修改后的链路

```text
冻结8192点BRAM
   ├─ 全帧Amax扫描 → 对称纵轴
   ├─ 两半帧Hann加权基波投影 → 相位差/细化周期/相位起点
   └─ 原BRAM按分数地址读相邻两点 → 有符号线性插值 → 240个Y点
         ↓
仅首次/切页发送page → 暂停刷新 → cle + add×240 → 同帧文本/刻度
         → 显式刷新曲线 → 恢复刷新 → UART停止位和间隔完成 → 释放帧
```

`Display_Fundamental_Aligner.v`使用两段各4096点的周期Hann窗，对选中的FFT基波格点作I/Q投影。
两段窗中心相距4096样点，CORDIC计算残余相位，按下式细化周期：

```text
Δφ = wrap(φ1 − φ0)，单位为turn
bin_fine = bin_coarse + 2 × Δφ
φ_origin = φ0 − Δφ/2
period_samples = 8192 / bin_fine
start_samples = wrap(−φ_origin) × period_samples
address[p] = start_samples + p × C × period_samples / (W−1)
```

相位为32-bit整圈码，细化bin为unsigned Q12.20，地址为unsigned Q12小数。
窗、I/Q乘法共用一个24×17有符号乘法器；角度用迭代CORDIC，除法用串行除法器。
CORDIC只求相位，因而不需要对模长作增益补偿。
负频偏的算术右移先在signed中间线上完成，避免unsigned相位减法将其变为逻辑右移。

两段投影幅值过低、相位差超界、基频非法时，返回未锁定，回退到原格点跨度、地址0起绘。
不会为得到稳定画面而捏造基波。此门限仅为显示置信度检查，不替代测量链路的有效性判断；
噪声、非谐波信号、漏检/错选基波仍需实测。显示细化值不修改频率文本、ILA测量结果或幅值标定。

## 屏幕事务及兼容性

顶层参数：

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| DISPLAY_PAGE_REFRESH | 0 | 首次/实际切页才发page；正数保留显式周期重同步选项 |
| DISPLAY_REFRESH_GUARD | 1 | 使用ref_stop/ref_star及ref曲线ID；不支持时设0 |
| DISPLAY_WAVE_ALIGNMENT | 1 | 基波相位/周期对齐；设0保留原格点插值 |

首次事务先发送三个FF清理可能被FPGA复位打断的命令，再发`ref_star`恢复可能遗留的暂停状态。
随后发送所需页面并等待切页间隔。同页后续事务不再发page。

默认单批发送顺序如下，每条命令都带三个二进制FF：

```text
ref_stop
cle 1,0
add 1,0,Y       # 顺序发送W条，不含换行注释
...其余曲线点...
...全部同帧测量文本、纵横轴文字...
ref 1
ref_star
```

**本轮没有验证TJC3224T128_011具体固件对这些刷新命令的支持，也没有模拟其内部显示引擎。**
UART仿真验证的是命令及传输时序，不能证明屏幕支持在暂停期间更新波形缓存且保持旧图。
若实屏仍在cle时清空、逐点刷新或不刷新，应先核对该型号指令帮助及屏幕工程，不能认定加了命令便已实现双缓冲。
关闭GUARD仍保留同页page修复，但cle/add的可见重画可能存在。当前TX-only接口无法读取ACK、
判断屏幕重启或保证屏幕解析速度；仅屏幕重启后应复位FPGA重发页面。

原本已有ready/valid背压和整帧冻结，继续沿用。发送途中改变页面/周期不修改正在发送的快照；
HOLD可在下一安全边界重绘同一帧。内部扩展状态为6-bit，ILA原5-bit接口保持不变，码17代表扩展刷新状态。

## 资源和时序边界

新增一个1024×16同步四分之一正弦ROM，设计意图使用一块RAMB18；新增一个共享DSP乘法器。
没有新增整帧缓存。此前实现已占47/50 BRAM、89/90 DSP；上述仅为结构预期，
新总占用、ROM推断、DSP映射和WNS须由新的综合/实现报告确认，不能沿用09:06的正时序结论。
对齐约需十余万算法时钟，串口发送仍是主要耗时；完整响应应实屏计时。

500kHz时每周期只有约8.19个ADC样点，线性插值改善像素阶梯但不能恢复已丢失的高频细节。
240像素及输入/采样带宽也限制可显示的谐波。此次并未把采样波形与连续模拟波形等同。

使用Vivado 2025.2 XSim，仅编译/展开/行为仿真：

| scripts/run_display_hmi_sim.ps1 | PASS：5个顶层；四组原协议回归及完整8192点新对齐链路，实际UART解码，检查page/刷新序列、全部像素、标定快照、HOLD、无信号、reset/STOP释放 |
| scripts/run_display_prepare_sim.ps1 | PASS：240×160、200×128、17×256三组旧计算路径回归 |
| scripts/run_measurement_debug_sim.ps1 | PASS：原子快照及实际顶层接口/采集许可契约；DSP IP为黑盒，不代表整机数值仿真 |
| 主机unittest discover | PASS：原116项；合并远端工具后新增3项另测通过，合计119项；无仪器访问 |

新UART端到端案例以20.37 bin（名义10185Hz）复合信号为输入，验证1T中点49.1us、右端98.2us，
3T中点147.3us、右端294.6us；两帧不同初相，只发送一次page，合计480个原始采样插值点。
这不是测量误差、任意组合或实际显示无闪烁的全范围保证。

## 用户手动构建与验收

1. 若Vivado工程已打开，先执行`source scripts/setup_display_prepare.tcl`注册两份新增RTL；
   或关闭后重开已更新的G_FPGA.xpr。确认Display_Sine_ROM、Display_Fundamental_Aligner在sources_1内，保存工程。
2. 用户手动综合、实现，核对新增资源仍在器件限额内，WNS/时序及DRC均满足要求；再生成bit和匹配LTX，手动下载。
3. 固定100kHz正弦、连续测量，保持wave页：文本继续更新，页面不应整页反复清空；检查曲线是否仍逐点消失重画。
4. 切1T/3T，检查时间刻度及周期端点；单次HOLD切页/跨度，应显示同一帧，不触发新的采集。
5. 改用已验证的多谐波组合并改变初相：畸变必须保留；左端按基波相位对齐，不能要求复合波左端必为0。
6. 测试屏幕/FPGA复位、无效新帧及切页恢复。记录实屏命令兼容性和刷新完成耗时，再开展正式验收。

本轮未更改模拟链路、FFT缩放、标定默认值、外部引脚或ILA IP配置。
